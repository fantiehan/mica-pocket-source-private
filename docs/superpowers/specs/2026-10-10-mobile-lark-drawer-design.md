# 移动端飞书侧栏模拟页设计

## 目标

在 `Documents/代码/html` 中创建一个可直接通过本地静态服务器访问的移动端网页，复刻 `reference.mp4` 中飞书深色会话页及账户侧栏交互。重点是侧栏开启与关闭、账户名称 `Tiehan Fan`、组织 `ByteDance`、延迟出现的 `Verified` 标识；聊天列表仅做静态背景。

## 参考视频量化结果

- 原视频：1320×2868，等价于 440×956 CSS 像素的 3×录屏。
- 侧栏开启后：账户轨道约 97px，主菜单约 281px，总宽约 378px，右侧保留约 62px 的聊天背景。
- 打开与关闭：整体从左侧滑入/滑出，持续约 300ms；背景同时变暗。
- `Verified`：抽屉稳定后约 700ms 延迟显现，以宽度展开和透明度渐入表现。
- 状态栏和灵动岛位于最上层，不随侧栏移动。

## 架构

页面不使用框架和远程 CDN。`index.html` 负责语义结构与静态内容；`styles.css` 负责手机画布、深色视觉、抽屉、图标和动画；`drawer-controller.js` 是可独立测试的状态控制器；`config.js` 集中保存账户信息；`app.js` 只负责把配置渲染到 DOM 并绑定控制器。

## 交互

1. 点击聊天页左上角账户区域，抽屉整体从左侧滑入。
2. 抽屉开启时右侧聊天内容保留但加深色遮罩。
3. `Verified` 在抽屉打开后延迟出现，以突出账户验证状态。
4. 点击右侧遮罩或按 Escape，抽屉滑出并回到聊天页。
5. 触发按钮同步 `aria-expanded`，抽屉与遮罩同步 `aria-hidden`。

## 视觉结构

- 画布最大宽度 440px，移动端占满视口；桌面端居中展示。
- 顶部状态栏固定，包含 19:42、录屏灵动岛、信号、Wi-Fi 和 37% 电量。
- 聊天页包含账户头、快捷头像、会话筛选、静态会话列表与底部导航。
- 抽屉左侧为账户轨道，右侧为账户卡片和 Profile、Wallet、Favorites、Log Into More Accounts、Contact Us、Manage Devices、Settings 菜单。
- 页面叠加低对比度斜向隐私水印，贴近参考视频观感。

## 测试与验收

- Node 内置测试验证控制器打开、关闭、Escape、销毁监听器和配置数据。
- 静态契约测试验证关键 DOM 节点、账户数据挂载点和动画参数存在。
- 浏览器以 440×956 视口验证初始页、打开侧栏、Verified 出现、遮罩关闭四个状态。
- 页面不请求外部资源，浏览器控制台不应出现错误。
